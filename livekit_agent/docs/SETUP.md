# Настройка Джарвиса: ключи, Telegram, телефон

Всё это можно ввести в панели управления (`Start-Panel.bat` или `python panel.py`) — она записывает `.env`, проверяет каждый ключ и умеет войти в Telegram без терминала. Ниже — где что взять.

| Что | Нужно ли | Зачем | Где взять |
|---|---|---|---|
| Ключ Claude | обязательно | «мозг» | console.anthropic.com |
| Ключ Deepgram | обязательно | распознавание речи | console.deepgram.com |
| Ключ ElevenLabs | нет | живые и клонированные голоса | elevenlabs.io |
| Telegram api_id/api_hash + номер | нет | писать людям, чат с Джарвисом, предупреждения | my.telegram.org |
| LiveKit URL/Key/Secret + номер | нет | входящие звонки | cloud.livekit.io |

Без необязательных пунктов Джарвис работает как обычный голосовой помощник; озвучка по умолчанию — бесплатный Edge TTS.

---

## 1. Claude (обязательно)

1. Зарегистрируйтесь на [console.anthropic.com](https://console.anthropic.com/).
2. **Settings → API Keys → Create Key**. Скопируйте ключ (`sk-ant-…`) — показывается один раз.
3. **Settings → Billing** — пополните баланс. Без денег на балансе API отвечает ошибкой «credit balance is too low», и Джарвис перестаёт отвечать.
4. В панели вставьте ключ → **«Сохранить и проверить»**. Проверка делает запрос на один токен (доли цента) и честно скажет, принят ли ключ и есть ли баланс.

> Подписка Claude Pro/Max и баланс API — разные счета. Подписка не оплачивает вызовы API.

Модель по умолчанию — Claude Haiku (быстрая и дешёвая). Другую можно указать в поле «Модель для разговора».

## 2. Deepgram (обязательно)

1. Зарегистрируйтесь на [console.deepgram.com](https://console.deepgram.com/) — есть бесплатный стартовый кредит.
2. **API Keys → Create a New API Key**, права по умолчанию подходят.
3. Вставьте в панель. Язык распознавания — поле «Язык речи» (`ru`, `uk`, `en`, …).

Если модель `nova-3` не понимает ваш язык или тариф, добавьте в `.env` строку `DEEPGRAM_MODEL=nova-2`.

## 3. Озвучка

- **Edge TTS** (по умолчанию) — бесплатно, без ключей. Голос: `ru-RU-DmitryNeural` (мужской) или `ru-RU-SvetlanaNeural` (женский), меняется полем «Голос Edge TTS».
- **ElevenLabs** — выберите в панели «Озвучка → ElevenLabs», вставьте ключ ([elevenlabs.io](https://elevenlabs.io/app/settings/api-keys) → API Keys).

### Свои голоса и смена голосом

В разделе **«Голоса»** добавьте пары «имя → ID голоса». ID берётся в ElevenLabs: Voices → нужный голос → значок «ID». Голос обязан быть в вашем аккаунте — панель проверит это при добавлении. Дальше говорите «смени голос на *имя*»: переключение происходит со следующей реплики, без перезапуска, и запоминается.

Имя произносится как есть, а распознавание речи может написать необычное слово иначе, чем вы его сохранили. Если Джарвис «не находит» голос, посмотрите в `logs/app.log`, как именно он услышал имя, и добавьте второй пресет с таким написанием (одному ID можно дать несколько имён).

## 4. Telegram (необязательно)

Джарвис использует **отдельный аккаунт Telegram**, не бота: бот не может написать человеку первым, настоящий аккаунт может.

1. Заведите отдельный аккаунт Telegram для Джарвиса. Понадобится номер телефона, на который придёт код (вторая SIM подойдёт).
2. Откройте [my.telegram.org](https://my.telegram.org/) → войдите **под этим номером** → **API development tools** → создайте приложение (название и описание любые).
3. Скопируйте **api_id** (число) и **api_hash**.
4. В панели, раздел Telegram: вставьте api_id, api_hash, номер → **«Сохранить»** → **«Войти в Telegram»**. Введите код, который придёт в приложение Telegram (или по SMS), а если включена двухфакторная защита — пароль.
5. Перезапустите Джарвиса (значок в трее → «Перезапустить»).

Что вы получаете:

- **Писать от имени Джарвиса:** «Напиши Егору, что я опоздаю». Получателя можно назвать по имени, которое Джарвис запомнил вместе с номером (`remember_fact` в категории `relationships`, значение с номером телефона), а также по номеру или @username.
- **Чат с Джарвисом:** напишите аккаунту Джарвиса — он ответит. **Первый написавший становится владельцем**, поэтому напишите сами сразу после входа. Владелец получает инструменты и память; все остальные — только обычный разговор без инструментов и без ваших данных. Сменить владельца — удалить `data/telegram_owner.json`.
- **Предупреждения:** мало места на диске, забита память, необработанная ошибка в логе — придёт сообщение владельцу.

> **Важно.** Telegram официально не поощряет автоматизацию обычных аккаунтов. Для личного использования с небольшим числом сообщений это на практике работает, но вы делаете это на свой риск: аккаунт Джарвиса могут ограничить. Не используйте это для рассылок.

Файлы `data/*.session` — это вход в аккаунт. Никому не отдавайте и не публикуйте.

## 5. Телефонные звонки через LiveKit (необязательно)

Джарвис может брать трубку на номере LiveKit. Исходящие звонки не поддерживаются. Схема: звонок → номер LiveKit → правило маршрутизации → комната → процесс `worker.py start`, который присоединяется к комнате и разговаривает.

1. Зарегистрируйтесь на [cloud.livekit.io](https://cloud.livekit.io/), создайте проект.
2. **Settings → Keys**: скопируйте URL проекта (`wss://….livekit.cloud`), API Key и API Secret в панель (раздел «Телефон: LiveKit») → «Сохранить и проверить».
3. **Telephony → Phone numbers**: купите номер. Наличие стран и цены зависят от LiveKit и меняются; сверьтесь в кабинете. Учтите, что звонить на иностранный номер с обычной SIM — это международный звонок по тарифу вашего оператора.
4. **Telephony → Dispatch rules → Create**:
   - **Rule type:** Individual (каждому звонку своя комната);
   - **Room prefix:** `jarvis-call-` (любой);
   - **Agent dispatch → Add agent:** имя **`jarvis`** — ровно так, `worker.py` регистрируется под этим именем;
   - **Inbound routing:** отметьте ваш номер.
5. Перезапустите Джарвиса: процесс `worker.py start` стартует автоматически, когда заданы ключи LiveKit. Позвоните на номер.

**Безопасность:** звонящему доступно то же, что вам у микрофона (в том числе управление компьютером). Не раздавайте номер.

## 6. Автозапуск и удаление

- Автозапуск с Windows: `INSTALL_JARVIS.bat` или `python install_autostart.py`. Убрать: `python install_autostart.py uninstall`.
- Автозапуск создаёт ярлык в папке «Автозагрузка», а не `.bat`: ярлык хранит путь как Unicode, поэтому работает и с кириллицей в пути.

## 7. Adobe

Ничего ставить не нужно: при запуске Джарвис сам устанавливает расширение-мост. После первой установки один раз откройте в After Effects (или Premiere) **Окно → Расширения → Jarvis Bridge**. Photoshop управляется через COM-интерфейс и расширения не требует; этот модуль пока не проверялся на настоящей установке Photoshop, Premiere Pro проверен слабее After Effects.

## 8. Где что лежит

| Путь | Что |
|---|---|
| `.env` | ключи и настройки |
| `data/` | память, заметки, дела, сценарии, сессии Telegram, пресеты голосов — **личное**, в git не попадает |
| `logs/app.log` | голосовой диалог; рядом `phone_worker.log`, `telegram_bridge.log`, `proactive_monitor.log`, `panel.log`, `supervisor.log` |
| `logs/tool_calls.log` | журнал всех вызовов инструментов |

Резервная копия — папка `data/` и файл `.env`.

## Если что-то не работает

**Джарвис не слышит или не отвечает.**
1. Панель → Настройка → «Сохранить и проверить» у Claude. Самая частая причина — пустой баланс API.
2. Панель → Состояние: запущен ли «Голосовой диалог». Если нет — `logs/app.log`.
3. Микрофон: Windows по умолчанию может использовать виртуальное устройство (SteelSeries Sonar, Voicemeeter), которое не несёт звук микрофона. Список устройств: `python worker.py console --list-devices`, затем укажите нужное в «Микрофон» / «Динамики» (номер или часть названия).

**Ошибка `UnicodeEncodeError` при ручном запуске `worker.py console`.** Консоль не в UTF-8. Выставьте `PYTHONIOENCODING=utf-8` и `PYTHONUTF8=1`; `app.py` делает это сам.

**Антивирус ругается на `keyboard`.** Клавиша F10 ставится глобальным хуком клавиатуры (та же техника, что у кейлоггеров). Код `sleep_wake.py` реагирует только на `WAKE_HOTKEY`, ничего не логирует и никуда не отправляет. Клавишу можно поменять в панели.

**Голос ElevenLabs «не существует».** Голос удалён из аккаунта или ID неверный — проверьте раздел «Голоса».

**Для тех, кто обновляет зависимости.** Не снимайте эти ограничения, не проверив последствия:
- `requirements.txt` держит `anthropic<1.0`: `livekit-plugins-anthropic` не дружит с внутренним HTTP-клиентом `anthropic` 1.x.
- В `worker.py` стоит `_strict_tool_schema=False`: Anthropic разрешает не больше 20 «строгих» инструментов, а их больше сорока.
- `livekit-plugins-elevenlabs` читает `ELEVEN_API_KEY`, а не `ELEVENLABS_API_KEY`, поэтому ключ передаётся аргументом явно.
- Модель ElevenLabs `eleven_v3_conversational` (эмоциональные теги вроде `[laughs]`) на момент написания ломала декодер аудио в живом диалоге — по умолчанию стоит `eleven_turbo_v2_5`.
