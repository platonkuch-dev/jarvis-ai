Голоса

Сохранённые голоса ElevenLabs. Скажите «смени голос на …» с любым из этих имён — переключится со следующей реплики, без перезапуска.

ИмяID голоса

Добавить голос

ID берётся в ElevenLabs: Voices → нужный голос → значок «ID». Голос должен быть в вашем аккаунте.

Камера бета
