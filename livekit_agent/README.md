# Джарвис — голосовой ассистент для Windows

Голосовой помощник, который слышит вас, отвечает голосом и умеет делать дела на компьютере: открывать программы, управлять окнами и файлами, работать в After Effects и Photoshop, запускать Claude Code, ставить напоминания, писать в Telegram и отвечать на телефонные звонки. В основе — [LiveKit Agents](https://docs.livekit.io/agents/), Claude (Anthropic), Deepgram и Edge TTS / ElevenLabs.

**Английская версия: [README.en.md](README.en.md).**

## Быстрый старт

**Проще всего — установщик.** Запустите `JarvisAI-Setup-<версия>.exe`: он ставит программу для текущего пользователя (права администратора не нужны), уже содержит Python и все библиотеки, не открывает консолей, добавляет ярлыки и запись в «Приложения». После установки откроется панель — введите ключи, и всё. Удаление — из «Параметры → Приложения» или ярлыком «Удалить Jarvis AI» (можно оставить данные или стереть вместе с ключами). Тихий режим: `Setup.exe /S [/D=папка] [/DESKTOP] [/AUTOSTART]`, `Uninstall.exe /S [/PURGE]`. Как собрать установщик самому — [installer/build.py](installer/build.py).

**Или из исходников:**

1. Установите [Python 3.11 или 3.12](https://www.python.org/downloads/) (при установке отметьте «Add python.exe to PATH»).
2. Скачайте проект и запустите **`Start-Panel.bat`**. При первом запуске он сам создаст окружение и поставит зависимости, потом откроет панель управления в браузере.
3. В панели введите два обязательных ключа — **Claude** и **Deepgram** — и нажмите «Сохранить и проверить». Панель сразу скажет, принят ли ключ и есть ли деньги на балансе.
4. Нажмите **«Запустить Джарвиса»**. В трее появится значок, скажите «Привет».

Остальное (Telegram, телефон, свои голоса) необязательно и включается позже там же. Подробные инструкции по каждому ключу — в **[docs/SETUP.md](docs/SETUP.md)**.

Хотите, чтобы Джарвис стартовал вместе с Windows — запустите `INSTALL_JARVIS.bat` (создаст ярлык автозагрузки и ярлык на рабочем столе).

## Панель управления

`python panel.py` (или пункт «Открыть панель» в меню значка в трее):

| Раздел | Что делает |
|---|---|
| Настройка | Ключи и параметры, проверка каждого сервиса кнопкой, вход в Telegram без терминала, запуск и остановка |
| Возможности | Полный список умений с примерами фраз; отмечает, что уже работает на вашем компьютере, а что требует настройки |
| Голоса | Свои голоса ElevenLabs: добавили имя и ID — говорите «смени голос на …» |
| Состояние | Какие части сейчас запущены |

Панель слушает только `127.0.0.1`, отвергает чужие Host-заголовки и требует токен, который создаётся при первом запуске. Ключи в браузер не возвращаются — видны только последние четыре символа.

## Что умеет

Полный список с примерами — в панели, раздел «Возможности». Коротко:

- **Программы и окна** — открыть/закрыть по названию, свернуть, переместить, нажать кнопку или ввести текст в окне (Windows UI Automation).
- **Работа «глазами»** — многошаговые задачи по реальному экрану через computer use (Claude Sonnet). Самая дорогая по токенам функция, включается, когда нет готового инструмента.
- **Файлы и система** — папки, поиск, заметки, скриншоты, громкость/яркость/Wi-Fi/блокировка, состояние ПК. Удаление — только в Корзину.
- **Adobe** — After Effects через скриптовый мост (основная, проверенная часть); Photoshop и Premiere Pro — экспериментально. Нужны установленные программы.
- **Программирование** — «давай покодим»: VS Code + Claude Code в отдельном терминале.
- **Планирование** — напоминания, несколько именованных таймеров («сколько осталось?», «отмени таймер»), календарь, список дел.
- **Сводка и новости** — «утренняя сводка»: дата, погода, события, дела, главные новости одной фразой; новости из RSS с фильтром по теме; можно повесить на триггер «каждое утро в 8:30». Без ИИ — бесплатно.
- **Справка** — прогноз погоды до 7 дней, курсы валют и криптовалют с пересчётом сумм.
- **Музыка** — «включи Rammstein» сразу включает на YouTube; Spotify и Яндекс Музыка — по просьбе.
- **Умный дом** — свет, розетки, климат, шторы, сцены через Home Assistant.
- **Почта** — чтение входящих (не помечает прочитанными) и отправка писем после вашего «да» (IMAP/SMTP, пароль приложения).
- **Сам по себе** — фоновые задачи («разбери загрузки и пришли в телеграм, что там»), которые идут, пока вы заняты другим; автоматика «когда …, сделай …» по времени, по запуску программы, по новому файлу в папке, по простою, по заряду. Рискованные шаги — только после вашего «да» в Telegram. Результаты и напоминания приходят голосом, а если вас нет у компьютера — в Telegram.
- **Экономно** — частые короткие команды («громкость 30», «пауза», «таймер на 5 минут», «открой телеграм», «который час») выполняются локально, без обращения к ИИ: бесплатно и быстрее. Дневной лимит расходов на ИИ задаётся в панели.
- **Память** — запоминает факты и предпочтения между сессиями; голосовые сценарии «когда я говорю …, сделай …».
- **Telegram** — отправка сообщений с отдельного аккаунта Джарвиса, чат с ним в Telegram, предупреждения о состоянии компьютера.
- **Телефон** — Джарвис берёт трубку на номере LiveKit (только входящие).
- **Голос** — бесплатная озвучка Edge или ElevenLabs с переключаемыми голосами; F10 усыпляет и будит, после тишины засыпает сам; разбудить можно и голосом — «Hey Jarvis» (локальная модель openWakeWord в `wake_models/`, без интернета).

## Как это устроено

```
микрофон → Deepgram (речь → текст) → Claude (решает и вызывает инструменты) → озвучка → динамики

app.py (трей, следит за процессами и перезапускает упавшие)
 ├─ worker.py console      голосовой диалог + F10 + автосон
 ├─ hud_bar.py             плашка статуса
 ├─ worker.py start        приём телефонных звонков      (если заданы ключи LiveKit)
 ├─ telegram_bridge.py     чат с Джарвисом в Telegram    (если выполнен вход в Telegram)
 ├─ proactive_monitor.py   предупреждения в Telegram     (то же условие)
 └─ panel.py               панель управления
```

В голосовом процессе дополнительно крутятся три фоновых цикла: напоминания (`tools/scheduling.py`), очередь фоновых задач (`tools/tasks.py`) и триггеры (`tools/triggers.py`). Всё хранится в `data/`, поэтому переживает перезапуск. Уведомления владельцу любой процесс кладёт в `data/notify_outbox.jsonl` (`notify.py`), а `proactive_monitor.py` отправляет их в Telegram.

Необязательные части стартуют, только когда для них есть настройки, поэтому свежая установка без Telegram и LiveKit запускается без ошибок. Если процесс падает, `app.py` перезапускает его; при пяти падениях за пять минут делает паузу на 30 минут, пишет вам в Telegram и потом пробует снова. Логи ротируются после 5 МБ.

## Сколько это стоит

Программа бесплатная, платите провайдерам за то, чем пользуетесь. Ориентиры (оценка на момент написания — цены меняются, сверяйтесь с сайтами):

- **Claude Haiku** (обычный разговор) — порядка $1/$5 за миллион входных/выходных токенов. Системный промпт и описания инструментов кэшируются, поэтому обычная реплика обходится в десятые доли цента.
- **Claude Sonnet** (только «работа глазами») — примерно вдвое дороже за токен, и каждый шаг несёт скриншот, то есть заметно дороже реплики.
- **Deepgram** — есть стартовый бесплатный кредит, дальше почасовая оплата.
- **Озвучка Edge** — бесплатно. **ElevenLabs** — по тарифу.
- **Телефон** — номер и минуты у LiveKit.

Подписка Claude Pro/Max и баланс API — разные вещи: подписка не оплачивает вызовы API. Если Джарвис «оглох и онемел» — первым делом проверьте баланс на console.anthropic.com (кнопка «Сохранить и проверить» в панели показывает это прямо).

## Безопасность

- Необратимые действия (сон, удаление/сохранение сценария) — только после явного голосового «да, подтверждаю»; проверка сделана в самих инструментах, а не только в промпте.
- Системные действия — белый список (`config.SAFE_SYSTEM_ACTIONS`). Запуск скриптов — только из `config.SCRIPT_WHITELIST` (по умолчанию пуст). Произвольного shell, `eval`, `exec` нет.
- Файлы — только в домашней папке, удаление — в Корзину. Сценарии не могут вызывать сценарии.
- Каждый вызов инструмента пишется в `logs/tool_calls.log`.
- **Telegram:** владельцем становится тот, кто пришлёт аккаунту Джарвиса одноразовый код из панели (раздел Telegram). Только владелец получает инструменты, память, уведомления и запросы на подтверждение. Остальным — обычный разговор без инструментов и без ваших данных, не больше `TELEGRAM_STRANGER_MAX_PER_DAY` ответов в день. Сменить владельца — кнопкой в панели.
- **Телефон:** управлять компьютером могут только номера из `PHONE_ALLOWED_NUMBERS`. Остальные звонящие — только разговор; их слова пересылаются вам в Telegram.
- **Фоновые задачи и триггеры:** каждый шаг проходит через `policy.py`. Безопасные (чтение, громкость, напоминания) выполняются сразу, шаги с последствиями (сообщения, закрытие программ, работа с экраном, файлы) ждут вашего «да» в Telegram, если вы явно не сказали «без подтверждений». Управлять задачами и триггерами изнутри задачи нельзя. Создание и удаление триггера — только с голосовым подтверждением.
- **Расходы:** `usage.py` считает реальную стоимость каждого вызова ИИ (`data/usage.json`); после `DAILY_BUDGET_USD` в день фоновая работа останавливается, а вы получаете уведомление.
- Личные данные (`data/`, `.env`, сессии Telegram, логи) лежат только на вашем компьютере и исключены из git. Перед публикацией своей копии запустите `python scripts/release_check.py`.

## Структура проекта

```
worker.py               точка входа агента: STT → LLM → TTS
app.py                  трей-приложение и надсмотрщик процессов
panel.py, panel_static/ панель управления (FastAPI + одна HTML-страница)
capabilities.py         каталог умений для панели
prompts.py              системный промпт
config.py               пути, белые списки, настройки из .env
telegram_bridge.py      чат в Telegram        telegram_login.py — вход из терминала (панель делает то же)
proactive_monitor.py    мониторинг ПК         sleep_wake.py — F10 и автосон
tools/                  инструменты (по одному модулю на область), registry.py собирает их
fast_path.py            частые короткие команды без ИИ
agent_loop.py           цикл «ИИ + инструменты» без голоса (Telegram, фоновые задачи)
policy.py, approvals.py уровни риска шагов и подтверждения владельца в Telegram
usage.py, notify.py     учёт расходов и дневной лимит; очередь уведомлений владельцу
telegram_owner.py       привязка владельца Telegram по одноразовому коду
tests/                  pytest, без сети и без ИИ
windows_control/        окна, UI Automation, зрение
adobe_cep_bridge/       мост к After Effects / Premiere
custom_tts/             адаптер Edge TTS
scripts/                установка, release_check.py
web/, web_api.py        необязательный браузерный клиент LiveKit (см. web/README.md)
```

## Для разработчиков

- Новый инструмент: модуль в `tools/`, регистрация декораторами `register_impl` + `register_tool` (см. любой существующий), импорт в `tools/__init__.py` и описание в `capabilities.py` — `scripts/release_check.py` напомнит, если забыли.
- Тесты: `.venv\Scripts\python.exe -m pytest` (без сети, без ИИ, в отдельной временной папке данных).
- Отладка голосового цикла в консоли: `python worker.py console` (список устройств: `python worker.py console --list-devices`).
- Известные особенности зависимостей и типичные проблемы — в разделе «Если что-то не работает» в [docs/SETUP.md](docs/SETUP.md).
