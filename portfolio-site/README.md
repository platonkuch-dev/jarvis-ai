# Portfolio site — JARVIS AI case study

Static site (HTML / CSS / JS + Three.js). No server needed: open `index.html`, or deploy the folder anywhere
(Netlify, Vercel, GitHub Pages, Cloudflare Pages).

## Before publishing — edit these
1. `src/main.js` → `SITE` block at the top: `fiverrUrl`, `email` (`name` is already Platon_ind). Then run `build.bat` (needs Node.js).
2. `index.html` → the hero copy and FAQ answers, so they match what you actually sell on Fiverr.

## Structure
- `index.html`   markup and content
- `style.css`    design tokens, layout, animations
- `src/main.js`  source: 3D scene, scroll animations, terminal demo
- `app.js`       built bundle (three.js included) — generated by `build.bat`
- `vendor/`      three.js r170 (MIT)

## Languages (EN / RU)
English text lives in `index.html`; Russian text is in `src/i18n.js` under the same `data-i18n` keys.
To change a phrase, edit it in both places, then run `build.bat`.
